Rclone Backup API

The Web UI and automations use the same REST API. Environment variables are imported once; API and UI changes then persist in SQLite.

OpenAPI 3.1 JSON

Examples

curl http://localhost:8080/api/status
curl http://localhost:8080/api/plans
curl -X POST http://localhost:8080/api/plans/<id>/run

If optional Basic authentication is enabled, add -u user:password. The private rclone RC API is intentionally not exposed.
